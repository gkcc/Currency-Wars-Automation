# 货币战争 · Codex 带教版

**主线目标：在本赛季奖励到期前，先达成最高段位奖励门槛，再尽可能领完其余限时奖励。**

这是一个刻意保持轻量的 **Codex 游戏带教工作区**，不是原先的 Windows 自动操控软件。Codex 负责观察、查攻略、综合经济/阵容/装备、提出整回合运营方案；用户通常只在每回合开头确认一次；之后由 Codex 使用当前实际可用且已授权的截图/输入工具完成操作、核对战果。用户不需要逐个点击，也不需要审核每次鼠标动作。

## 确认与执行的边界

每轮只审批一份 **简短的全局运营方案**，不在常规单次刷新、购牌、装备转移后反复请求同一审批。资源与商店变化就局部重算；若经济预算方向、核心阵容或当前风险发生重大变化，再请求用户重审。

默认不写新代码、不训练本地模型、不跑测试、不做 PR、不升级控制器、不为了完美算法而拖延游戏。游戏操作必须经过当前会话有权调用的可靠工具；旧截图、旧会话及旧权限不可重用。

## 重要：这个主线不含旧 Windows 控制器

为避免污染上下文，原 GUI、Worker、MCP、本地求解器、OCR 工程、测试、数据导入和上百份研发交接 **都从 main 移走了**。它们没有丢失，完整版本位于 [归档分支](https://github.com/gkcc/Currency-Wars-Automation/tree/archive/pre-coaching-20261016-895ba72)，对应提交 895ba7228ab091d81764be92886e3c433e90cbe1。

**这次整理不等于已配置好 Codex 的鼠标/截图工具，也不保证无需输入工具就能自动打游戏。** 如当前 Codex 环境缺少经授权、可用的电脑操作工具，先明确告知用户缺口；不要偷偷恢复旧运行时或临场研发新控制器。详见 [归档与工具](docs/ARCHIVE.md)。

原游戏正在运行时，远端 main 的变动本身不会关闭本机进程；不要在活跃控制器仍使用旧文件时强制拉取、重装或热替换。
