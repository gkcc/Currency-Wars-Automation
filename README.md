# 货币战争 · 纯截图战略带教（Codex 操作备用）

**主线目标：在本赛季奖励到期前，先达成最高段位奖励门槛，再尽可能领完其余限时奖励。**

这是一个轻量的 **纯截图战略带教工作区**：**默认用户自己操作、截图，小青蛙等 AI 教练提供整回合运营建议**；只在用户显式要求时切换为 Codex 代操作。仓库保留独立的 Windows 截图/键鼠脚本作为可选工具，不重新引入旧 Worker/MCP/求解器。我们的验收是可靠通关、少纠错和实际领奖，不是点击自动化的完成度。

## 确认与执行的边界

每轮由用户提供当前截图，AI 教练先判定现况、需要时只请用户补一张关键详情，之后给出 **完整而简短的整队运营方案**：买卖与过渡退出、经济投入与停止条件、装备与前后台。用户快速操作，遇关键商店变化或严重战斗信号再补图。**不逐按钮汇报，也不把“这张牌有用”替代整队净收益。** 仅当用户选择 Codex 代操作时才使用受控键鼠工具，并遵守当前授权。

默认不写新代码、不训练本地模型、不跑测试、不做 PR、不升级控制器、不为了完美算法而拖延游戏。游戏操作必须经过当前会话有权调用的可靠工具；旧截图、旧会话及旧权限不可重用。

## 重要：新主线仅补回最小 Windows 输入工具

为避免污染上下文，原 GUI、Worker、MCP、本地求解器、OCR 工程、测试、数据导入和上百份研发交接 **都从 main 移走了**。它们没有丢失，完整版本位于 [归档分支](https://github.com/gkcc/Currency-Wars-Automation/tree/archive/pre-coaching-20261016-895ba72)，对应提交 895ba7228ab091d81764be92886e3c433e90cbe1。

新主线新增独立的 `tools/game_io.py`：只做当前游戏窗口截图、悬停、查看详情、滚动，以及方案批准后的键鼠操作。Windows 下需要 Python 与 Pillow；操作必须检查前台、窗口/进程身份、旧控制器冲突及 STOP。**这不是旧 Worker 的完整输入安全等价替代品**；它不会判断某次点击是否为购买，也没有常驻 F8 监听器。必须先由获授权的操作者在当前 Windows 环境确认工具能实际截图和点击，不能因代码存在就声称实机可用。详见 [使用手册](docs/TOOLS.md) 与 [归档说明](docs/ARCHIVE.md)。

原游戏正在运行时，远端 main 的变动本身不会关闭本机进程；不要在活跃控制器仍使用旧文件时强制拉取、重装或热替换。
