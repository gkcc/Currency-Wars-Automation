# 实战运营手册（由仓库历史成功局提炼）

以下是旧 Codex 实战与2026-10-17两局复盘中可复用的运营经验，**不是已经验证的本赛季固定最优打法**。证据在 evidence/ 两份完整局复盘以及归档分支 handoff/2026-10-07/README.md；旧局角色、金币和目标全部失效，不自动继承。

## 1. 先把本局奖励目标放在战略首位

用户要求：**先达到最高段位对应的限时奖励门槛，再清理剩余奖励。** 冲段阶段宁可用高成功率、较稳定的路线，也不为了探索理论最优阵容损失整局；达到门槛并实领后可适当降低挑战难度刷剩余缺口。每局记录目标奖励与是否实际领取。

## 2. 奖励、指南、容量

- 每节点及时发现并领取奖励球、选择、武装箱等；不以动画消失替代实际领取确认。
- 满备战席可能阻塞赠送角色的奖励。只卖经确认无用、且确实需要腾位的牌；不能因为人口满了就推断备战席有空位。
- 奖励处理后核对已选攻略和任务/羁绊路线，不能继续按照早期已完成的奖励目标重复刷。攻略标题“超频博弈适用”表示普通模式可用、超频也可用，**不等于只限超频**；但经济规则仍区分两模式。
- 稳定攻略文字可以按版本记笔记复用；动态金币、商店、库存、装备位置、任务进度需重新看当前界面。

## 3. 商店、买卖与经济

- 综合比较当前购买缺口、对子升星、过渡羁绊、免费刷新、付费刷新预算、升级人口、下一战生存和后期资源价值。不要把“刷几次”写成无条件固定数字。
- 通常先购买明显的当前缺口，用掉真正可用的免费刷新；付费刷新需设实际次数/金币停止条件以及刷出目标后的购牌预留，再根据当前局势升级。
- 标准博弈利息和超频博弈的机制不可混用。历史常用50金币利息参考线**不是强制要求**；低血量、关键升星、局末没有后续结息时，可以依据当前局面选择转战力。
- 需要卖掉不再补当前羁绊、没有升星/转型价值的过渡牌，同时保留关键核心、接近完成的对子、未来必要组件。**每个过渡位要有退出条件；卖主C散牌前核本局是否还要追三**。不要只看人物头像或颜色就出售。
- 历史可验证操作键：商店打开时 D 刷新、F 购买经验。使用前仍须核当前游戏的可用页面与实价；按钮发出不是交易成功。
- 已完成任务和有价值的奖励型投资，可改变本轮战力与长期收益，不能只看伤害面板。

## 4. 装备和场位

- 真正读取**可用库存**和角色已有穿戴。右侧“装备追踪”只是目标提示，不能直接当作已持有。
- **装备可转移，但保留角色卸装消耗有限工具**；卖掉角色，身上装备会返库存，卖人本身又会损失角色价值。过渡角色可先穿，核心到来再比较转移收益与剩余工具，避免低血量时装备闲置或反复拆装。
- 合成、冶金炉、重铸、特权卡是否可逆、实际消耗和完成任务的收益要单独判断。冶金炉可直接对角色使用，需注意整名角色穿戴；**静态配方存在≠当前可用材料/菜单允许/实际合成**。“两件量产型装甲→很硬的甲”是4.6静态配方，但历史页面未显示不能据此断言配方不存在。
- 位置不仅为了凑满人口；核前后台容量、同场投资/羁绊、角色定位与装备相互作用。历史曾出现尝试在已满4人的前台塞第5人，不能复犯。

## 5. 计划允许向未来看，但不假装知道未来随机结果

- 攻略和推荐角色/装备是可验证的强基线；结合现有高星角色、已有投资和商店机会，必要时允许动态偏离。
- 等级影响刷新费用分布、牌池可能有限，但**本仓库没有可直接证明当前版本每费每角色库存数、是否共享池、完整费用概率的可靠材料**。严禁把旧攻略/外部帖子当已确认机制。若该机制影响大额搜牌，先查当前可靠规则或直接按不确定性运营。
- 每次大额决策比较立即提升战斗胜率 vs 利息与后续购买概率；执行一段、看实际新局面、滚动规划，而不是赌整局预言。
- 如果没有完整模拟器或可靠概率资料，不为了计算理想全局最优延误眼前有效出战。
- 选择过渡位、卖牌或放弃攻略高亮候选时，必须同时比较**现有整队与成型目标整队**，写出谁替谁、前后台合法性、羁绊变化、装备与代价；不能仅因旧小羁绊仍有用就永久保留。

## 6. 真正实战暴露的问题

- 历史SSS/100血实战中，2-1备战约2.39分钟，2-5约0.46分钟；但3-7特殊节点约29.91分钟，**并非整局每节点都快**。
- 第一完整局处理过14或19个奖励球、连续刷新、整套装备调整和羁绊达成；一部分动作无效果时通过真实新帧纠正。
- 第二局正式结算A/51血，记录时段3.17小时、241条操作收据，**不是纯模型决策耗时**。
- 常见失误：商店关闭时按D、动态装备库存缩排后沿用旧坐标、动画未完成就连续拖动/出售、看错角色姓名/星级、忽略最后几轮利息价值下降。

这些记录证明 Codex 监督实战曾成功通关，**不能证明当前版本任何阵容稳赢，也不证明过去短节点的速度可普遍复现。**

## 7. 2026-10-17 纯截图晋升赛失败后新增的三项纠偏

1. **战斗超时优先诊断输出/行动循环**：1-7附近出现“没人死但打不完”，1-9进一步重扣血，足以要求重新评估；不能持续只补治疗、保持原七人等下轮。超时与模型网络响应慢不是同一个问题。
2. **预算有停止条件而非习惯数字**：每轮按立即升星/核心/条件转型/跳过牌分层，写可支出金币、留资理由与刷新停止条件；末关若已确认无下一次利息结算，不把50金币当神圣目标。
3. **最后一次全图核验**：买卖/刷新结束再确认场上位置、关键羁绊、实际已穿装备与闲置库存；只有出战前的实际截图能支持“装备已经装好”，提出过配装建议不能替代操作结果。历史[两局复盘](SCREENSHOT_COACHING_TWO_MATCH_REVIEW_2026-10-17.md)中缺最终配装图，不能倒推失败责任。

**静态机制示例（须按当前版本再核）**：据4.6复盘的代码审查校正，白厄自身一星/二星时，其他前台队友每颗星的名义强度系数分别为40/80个百分点；不能把白厄二星的二星前台队友误计为只贡献80，也不能把名义强度百分点直接当作最终伤害百分比。
