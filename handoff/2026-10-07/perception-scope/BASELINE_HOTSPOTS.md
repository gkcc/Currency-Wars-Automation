# 阶段读图成本：PR12 基线热点

## 当前结论

同环境真实历史图片的预热实读表明，主 OCR 占总读图时间 **85.83%**。只跳过阵容读取，在本公共环境约能移除 3.40% 的原调用成本；领奖范围再跳过展开商店的读取，三张领奖图合计对应约 5.36% 的原调用成本。这是按现有区间测得的潜在减少量，尚不是候选实际收益。

再对 q01/q00 的主 OCR 拆分，文字识别约占两图主 OCR 的 **81.6%**，文字检测约占 18.0%。后续较大收益的方向是减少与当前阶段无关的文字框识别，并保留页面、提示和动作前置证据；单纯跳过模板或规则不是主要热点。本批审查发现，直接省略中央文字可能漏掉模态弹窗却仍判为备战，因此暂不改变全帧主 OCR。最终候选仅减少结构化与附加读取，实际结果见 [RESULTS.md](RESULTS.md)，并未证明总读图提速。

## 来源与执行范围

基线是完整 PR12：`5e46351372ff26980a92a9806909c732607f50ea`。旧仓库保持未修改；源码测量前后 SHA256 一致。原始数据见 [`pr12-full.json`](pr12-full.json)，主 OCR 分项见 [`primary-ocr-components.json`](primary-ocr-components.json)。

固定顺序为 q00、q01、q02，随后 r00、r01、r02、r03、r04、r05、r06。十张图片均先与现有 manifest 核 SHA256，没有新截图、图像裁剪输入或控制器；完整原 PNG 直接交生产 `Perception.read`。

同一进程先执行一遍冷起序列，再执行一遍预热序列。每张实读使用 `force=True`，随后再用 `force=False` 对同一 PNG 测缓存：共 20 次实读与 20 次缓存读取。缓存返回的 `elapsed_ms` 属于原计算，缓存成本由外层时钟独立测量，不拿该旧值冒充缓存耗时。所有缓存返回语义都与对应实读一致。

在导入 ONNX Runtime 前设置 `ORT_DISABLE_TELEMETRY=1`，随后调用 `disable_telemetry_events()`；只用已安装的本地模型。没有网络调研、模型下载、游戏输入或游戏采集。

## 冷起与缓存

首次 q00 实读 1.8348 秒，其中 OCR 引擎构造 0.2163 秒。ONNX Runtime/RapidOCR 导入 0.1443 秒，生产模块导入 0.0023 秒，独立列示；不加到每张图。

冷起序列十张实读合计 12.7056 秒，预热序列 12.4711 秒；这只是单次同序列对照，不能把差值全部归因于初始化。主 OCR 存在单次运行波动。

预热十次同图缓存合计约 0.0124 秒，冷起序列的十次缓存约 0.0140 秒。该毫秒级缓存收益只适用于相同字节和适用读取范围，不能代替新帧真实识别。范围切换时也不能拿另一个范围的缓存当新计算。

## 最终对比脚本

[`replay_currency_wars_perception_scope.py`](../../../tools/replay_currency_wars_perception_scope.py) 支持在独立进程分别运行完整读取与阶段读取。阶段模式固定对 q00/q01/q02 请求 `rewards`，对七张刷新图请求 `economy`；完整模式显式请求 `full`，也支持尚无 scope 参数的 PR12 默认完整读取。

```bash
ORT_DISABLE_TELEMETRY=1 PYTHONPATH=/path/to/test-deps python -B -X utf8 tools/replay_currency_wars_perception_scope.py \
  --code-root . --mode full --output offline-results/perception-full.json

ORT_DISABLE_TELEMETRY=1 PYTHONPATH=/path/to/test-deps python -B -X utf8 tools/replay_currency_wars_perception_scope.py \
  --code-root . --mode scoped --compare-to offline-results/perception-full.json \
  --output offline-results/perception-scoped.json
```

两条命令顺序运行，测量期间不并行跑其他 OCR/性能任务。输出分别保存首图引擎初始化、强制真实实读、同图缓存、具体方法调用及互斥组件。主 OCR、数字 OCR、商店内部 OCR 和检测/识别成员的包含关系保留。共同页面、字段、金币、奖励控件如有差异会原样列出，不能悄悄称为等价；显式省略的阶段字段另按实际读取契约复核。

本文件保留 PR12 热点测量。最终候选的阶段读取实测与边界已另记于 [RESULTS.md](RESULTS.md)；此处潜在减少量不等于候选实际收益，其它页面的真实回退成本仍未测量。
