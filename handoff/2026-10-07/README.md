## 本局以后必须保持的用户规则

1. 节点顺序：领完全部奖励/选择/箱子 → 右上第二入口创业指南 → 清理不需要的牌 → 购买当前明确缺口 → 免费刷新并处理新缺口 → 明确付费搜牌预算与停止条件 → 再决定人口经验 → 上场/装备/炉/特权卡 → 本机ROOT看新帧逐次验收 → 单次出战。当前缺口、免费刷新和搜牌留资没有解决前，不先花经验占用购牌预算；满席仅为领取已阻塞奖励做必要腾位。
2. 脚本能做的机械操作交给脚本。D 刷新、F 买经验应通过同一 broker 使用；免费次数、金币、经验和效果需要回读，不能盲连按。卡住后回传，让主管判断并有界手操，再继续。
3. 所有卡点分类：A 特殊场景或策略判断，B 通用脚本缺陷，C 尚未确定原因。B 抽象后参考成熟通用解法；每一整局后集中修，后续完整局统计是否重犯。
4. 已读取的装备、策略、羁绊等稳定信息按版本缓存，更新后再读；钱、奖励、角色、任务进度等动态事实需要新证据。
5. 开图鉴小书顺手优先；已有选项按 tier 和目标阵容/已选策略适配。已完成巡海游侠与减益路线后，选攻略尽量避开相同路线，主动推进尚缺奖励。
6. 角色位置尽量与攻略一致；策略强制同场的角色必须安排格子，必要时调整目标阵容或升人口。非攻略且不补羁绊的牌优先卖；攻略缺口标记重要，但对子不等于无条件购买。
7. 普通模式有利息；当前满血连胜先存50，花溢出和高收益关键缺口。50花到30每轮少2利息，可与剩余回合和战力收益比较；最后一战不为不存在的下轮利息留钱，也不为清零买无用牌。
8. 倍速保持2x，禁止无证据切换；炉主动评估但不随意洗主C全套。
9. 局后领取羁绊链路、预期收益（含限时）、晋升奖励；先永久优势强化，再考虑升晋升强度。提前根据奖励缺口规划，不依靠碰运气完成成就。
10. 一次只允许一个真实游戏输入控制器。前台、物理输入、窗口/进程身份、暂停/CAS/epoch、输入收据和单次出战审查不得绕过。
